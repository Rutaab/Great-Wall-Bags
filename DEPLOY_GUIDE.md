# HoBags — Full Deployment Guide (Hostinger VPS)

## Prerequisites

- Hostinger VPS (Ubuntu 22.04 / 24.04 recommended)
- Domain name pointed to the VPS IP (e.g. `hobags.com`, `www.hobags.com`)
- SSH access to the VPS
- Node.js 18+ and Rust 1.70+ installed on VPS

---

## 1. VPS Initial Setup

```bash
# SSH into your VPS
ssh root@YOUR_VPS_IP

# Update system
apt update && apt upgrade -y

# Install required packages
apt install -y curl git build-essential pkg-config libssl-dev nginx redis-server

# Install Node.js 20 (LTS)
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt install -y nodejs
node -v    # should be v20.x
npm -v     # should be 10.x

# Install Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
source "$HOME/.cargo/env"
rustc --version   # should be 1.70+
cargo --version
```

## 2. What to Upload (and What NOT to Upload)

### Frontend (`hobags-frontend/`)

| Upload? | Item | Reason |
|---------|------|--------|
| YES | `src/` | Source code — needed to build |
| YES | `package.json` | Dependency list |
| YES | `package-lock.json` | Locked dependency versions |
| YES | `tsconfig.json` | TypeScript config |
| YES | `vite.config.ts` | Vite build config |
| YES | `tailwind.config.js` | Tailwind CSS config |
| YES | `postcss.config.js` | PostCSS config |
| YES | `index.html` | Vite entry HTML |
| YES | `public/` | Static assets (icons, etc.) |
| NO | `node_modules/` | **Do NOT upload** — run `npm install` on VPS |
| NO | `dist/` | Build output — generated by `npm run build` |

### Backend (`hobags-backend/`)

| Upload? | Item | Reason |
|---------|------|--------|
| YES | `src/` | Rust source code |
| YES | `Cargo.toml` | Dependency manifest |
| YES | `Cargo.lock` | Locked dependency versions |
| YES | `.env` | Environment config (edit JWT_SECRET first!) |
| YES | `migrations/` | Database schema |
| YES | `.cargo/` | Cargo config |
| NO | `target/` | **Do NOT upload** — build artifacts (~500MB+). Run `cargo build --release` on VPS |
| NO | `hobags.db` | **Do NOT upload** — SQLite database is auto-created on VPS |

### Summary Rule

```
# Frontend: upload source, install deps, build on VPS
scp -r src/ package.json package-lock.json tsconfig.json vite.config.ts \
         tailwind.config.js postcss.config.js index.html public/ \
         root@YOUR_VPS:~/hobags/frontend/

# Backend: upload source, build on VPS
scp -r src/ Cargo.toml Cargo.lock .env migrations/ .cargo/ \
         root@YOUR_VPS:~/hobags/backend/

# Config files
scp backend/nodeploy_nginx.conf root@YOUR_VPS:~/hobags/
```

## 4. Build & Configure Backend

```bash
ssh root@YOUR_VPS_IP

cd ~/hobags/backend

# 1. Edit .env with production values
nano .env
```

### `.env` — Production Settings

```env
DATABASE_URL=sqlite:./hobags.db?mode=rwc
REDIS_URL=redis://127.0.0.1:6379
JWT_SECRET=<GENERATE_A_STRONG_SECRET_HERE>
HOST=0.0.0.0
PORT=3001
```

Generate a strong JWT secret:
```bash
openssl rand -base64 64
# Copy the output and paste it as JWT_SECRET in .env
```

```bash
# 2. Build backend (release mode — takes a few minutes)
cargo build --release

# 3. Run DB migrations
# (automatically handled on first startup via sqlx migrations,
#  or manually if needed)

# 4. Test the backend
./target/release/hobags-backend
# Press Ctrl+C to stop

# 5. Create a systemd service so it starts on boot
sudo nano /etc/systemd/system/hobags-backend.service
```

### `/etc/systemd/system/hobags-backend.service`

```ini
[Unit]
Description=HoBags Rust Backend
After=network.target redis.service

[Service]
Type=simple
User=root
WorkingDirectory=/root/hobags/backend
ExecStart=/root/hobags/backend/target/release/hobags-backend
Restart=always
RestartSec=5
Environment=RUST_LOG=info

[Install]
WantedBy=multi-user.target
```

```bash
# Enable and start the backend
sudo systemctl daemon-reload
sudo systemctl enable hobags-backend
sudo systemctl start hobags-backend

# Check status
sudo systemctl status hobags-backend

# View logs
sudo journalctl -u hobags-backend -f
```

## 5. Build & Configure Frontend

```bash
# On VPS
cd ~/hobags/frontend

# 1. Install npm dependencies
npm install

# 2. Update the API URL for production
```

> **Important**: The frontend in `src/services/api.ts` currently has `API_BASE = 'http://localhost:3001/api'`. For production behind nginx, you need to change it to use the relative path `/api` so it goes through the nginx reverse proxy.

Edit `src/services/api.ts`:
```bash
nano src/services/api.ts
```
Change line 1 from:
```ts
const API_BASE = 'http://localhost:3001/api'
```
to:
```ts
const API_BASE = '/api'
```

```bash
# 3. Build frontend for production
npm run build

# This creates the dist/ folder with static files
# Verify:
ls -la dist/
```

## 6. Configure Nginx Reverse Proxy

```bash
# On VPS
cd ~/hobags

# Edit the nginx config with your actual domain name
nano nodeploy_nginx.conf
```

### Changes needed in `nodeploy_nginx.conf`

1. Replace `hobags.com` and `www.hobags.com` with your actual domain
2. Replace SSL cert paths with your actual cert locations
3. Change the frontend upstream from port `5173` (Vite dev) to serve static files directly

Since you'll serve the built frontend (`dist/`) as static files (not via Vite dev server), update the config:

### `/etc/nginx/sites-available/hobags`

```nginx
# HTTP → HTTPS redirect
server {
    listen 80;
    server_name yourdomain.com www.yourdomain.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name yourdomain.com www.yourdomain.com;

    # SSL — use Let's Encrypt / Certbot
    ssl_certificate     /etc/letsencrypt/live/yourdomain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/yourdomain.com/privkey.pem;
    ssl_protocols       TLSv1.2 TLSv1.3;
    ssl_ciphers         HIGH:!aNULL:!MD5;

    # Security headers
    add_header X-Frame-Options DENY;
    add_header X-Content-Type-Options nosniff;
    add_header X-XSS-Protection "1; mode=block";
    add_header Strict-Transport-Security "max-age=63072000" always;

    # Gzip
    gzip on;
    gzip_types text/plain text/css application/json application/javascript image/svg+xml;
    gzip_min_length 256;
    gzip_comp_level 6;
    gzip_vary on;

    # Static frontend assets (built by Vite)
    root /root/hobags/frontend/dist;
    index index.html;

    # Cache static assets aggressively
    location /assets/ {
        expires 1y;
        add_header Cache-Control "public, immutable";
        try_files $uri =404;
    }

    # API requests → proxy to Rust backend
    location /api/ {
        proxy_pass http://127.0.0.1:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_buffering on;
        proxy_buffer_size 4k;
        proxy_buffers 8 4k;
        proxy_busy_buffers_size 8k;
        proxy_connect_timeout 5s;
        proxy_send_timeout 10s;
        proxy_read_timeout 30s;
    }

    # SPA fallback — all other routes serve index.html
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

```bash
# Copy config and enable it
sudo cp ~/hobags/nodeploy_nginx.conf /etc/nginx/sites-available/hobags
sudo ln -sf /etc/nginx/sites-available/hobags /etc/nginx/sites-enabled/
sudo nginx -t          # Test config for syntax errors
sudo systemctl reload nginx
```

### Expected behaviors:

| Scenario | Behavior |
|----------|----------|
| Visit `https://yourdomain.com` | Redirects to `/account` |
| Not logged in | Redirects to `/login` |
| Log in with valid credentials | Redirects to `/account` (profile) |
| Session expired | JWT expiry detected → redirected to `/login` |
| Already logged in, visit `/login` | Auto-redirects to `/account` |

## 13. Troubleshooting

| Problem | Likely Cause | Fix |
|---------|-------------|-----|
| `502 Bad Gateway` on API calls | Backend not running | `sudo systemctl restart hobags-backend` |
| `Cannot GET /account` | SPA fallback not configured | Check `try_files $uri $uri/ /index.html;` in nginx |
| Blank white page | API URL wrong or CORS | Check `src/services/api.ts` uses `/api` (not `localhost:3001`) |
| Backend won't start | Port 3001 in use | `lsof -i :3001` then `kill <PID>` |
| `npm run build` fails | Missing peer deps | Run `npm install` again |
| `cargo build` fails with linker errors | Missing system libs | `apt install build-essential pkg-config libssl-dev` |
